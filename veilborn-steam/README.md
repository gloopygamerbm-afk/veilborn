# Veilborn — Running it & Shipping to Steam

## Play it right now (no install)
Double-click `index.html` (Chrome / Edge / Firefox). Phaser is bundled in `lib/`, so it works offline.

| Action | Keyboard | Controller |
|---|---|---|
| Move | A / D or ← → | Left stick / D-pad |
| Jump (press again = double jump) | Space / W / ↑ | A |
| Cast spell | Z / X / Left Click | X |
| Cycle spellbook | Q | LB |
| Powers (3 slots) | 1 / 2 / 3 | B / RB / RT |
| **Inventory (stops time)** | **F** | Y |
| Interact (doors) | E | D-pad Up |
| Pause | Esc | — |

## Put it on Steam (Windows/Mac/Linux)
Steam can't run a browser game directly; you wrap it in **Electron** (already set up here: `main.js` + `package.json`).

1. Install Node.js LTS: https://nodejs.org
2. In this folder:
   ```
   npm install
   npm start          # test as a desktop app (F11 = fullscreen)
   npm run dist       # builds dist/win-unpacked/Veilborn.exe
   ```
3. Create a Steamworks account and pay the one-time **Steam Direct fee ($100 per game)**: https://partner.steamgames.com
4. Create your app, set up the store page (capsule art, screenshots, trailer, description), age rating questionnaire, tax/bank info.
5. Download the Steamworks SDK → `sdk/tools/ContentBuilder`. Put `dist/win-unpacked` contents in `content/`, write `app_build.vdf` + `depot_build.vdf` (templates are in the SDK), then run `steamcmd +run_app_build`.
6. Set the launch option in Steamworks to `Veilborn.exe`, set the build live on a branch, submit for review (takes a few days).
7. Optional: achievements / cloud saves via the `steamworks.js` npm package (call `init(appId)` in `main.js`). Saves currently use browser `localStorage`, which Electron keeps on disk automatically.

**Before you sell it:** you own the heroine sprite sheet you uploaded (make sure it's yours or properly licensed for commercial use). All other art, sound and music in this project is generated by code, so there are no third-party licenses to worry about.

## Put it on iOS and Android (Phones & Tablets)
See [README-MOBILE.md](file:///C:/Users/emili/.gemini/antigravity/scratch/veilborn-steam/README-MOBILE.md) for full instructions using **Capacitor**:
- **Android**: Build `.apk` and `.aab` for Google Play Store with Android Studio (works on Windows/Mac).
- **iOS**: Build `.ipa` for TestFlight and App Store with Xcode on Mac.
- **PWA**: Instant mobile play via "Add to Home Screen" with zero fees.
- **Touch Controls**: On-screen D-Pad (`◀`/`▶`), `JUMP`, `ATK`, `[E]`, and `BAG [F]` buttons are built-in and auto-detect touch screens!
